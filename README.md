# ADET Midterm: Backend API

A fully functional NestJS REST API deployed on Render and connected to a live Aiven MySQL database. Developed for Applications Development & Emerging Technologies.

## 🚀 Tech Stack
* **Framework:** NestJS / Node.js
* **Database:** MySQL (Aiven Cloud)
* **Deployment:** Render Web Service

## ⚙️ Features
* Full CRUD operations (Create, Read, Update, Delete).
* User Authentication (Register/Login).
* Modular architecture (Controllers, Services, Modules).

## 🌐 Live Endpoint
* `https://midterm-backend-bfbk.onrender.com`
